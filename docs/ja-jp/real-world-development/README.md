現実的なシナリオ、完成したアプリケーション、共有バックログを使って、ソフトウェア開発ライフサイクル全体で GitHub Copilot を体験します。変更の計画、コードの作成、動作確認、プルリクエストのレビュー、エージェントを使った作業管理を繰り返しながら進めます。

## シナリオ

架空のボードゲーム向けクラウドファンディング企業、Tailspin Toys に新しく加わった開発者として作業します。チームのバックログは GitHub issue として登録済みです。カテゴリやパブリッシャーによる絞り込み、ページネーションなどの機能開発に加え、アクセシビリティやコーディング標準の改善にも取り組みます。

## 作業環境を選ぶ

GitHub Copilot は、開発者が選んだ環境で利用できます。作業方法に合った環境を選択してください。各ワークショップは独自のセットアップから始まり、共通の Tailspin Toys シナリオを使います。

### [GitHub Copilot CLI][cli]

ターミナルでエージェント型アシスタントを使います。Plan モードと Autopilot モード、命令、スキル、カスタム エージェント、Playwright MCP、Agent Merge、便利な slash command を体験します。

### [GitHub Copilot app][app]

デスクトップ アプリでエージェント セッションを並行して実行し、セッション モードを切り替え、Canvas で共同作業し、GitHub issue とプルリクエストを管理します。

### [GitHub Copilot cloud agent][cloud]

GitHub issue を非同期エージェントに割り当て、作業を案内して進捗を監視し、作成されたプルリクエストをレビューします。

### [Visual Studio Code][vscode]

Visual Studio Code と GitHub Codespaces で GitHub Copilot を使います。エディターを離れずに Copilot Chat の agent mode、MCP server、カスタム エージェントを利用します。
