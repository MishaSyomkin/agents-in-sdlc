**[GitHub Copilot cloud agent](https://docs.github.com/copilot/concepts/agents/cloud-agent/about-cloud-agent)** を使うと、GitHub Copilot がクラウド上で非同期に作業できます。GitHub で作業を割り当てると、cloud agent はバックグラウンドでリポジトリを調べて変更を加え、プルリクエストを作成します。その間、開発者はほかの作業を進められます。

演習では、まず cloud agent が従うカスタム命令を追加し、GitHub issue を割り当てて実装を依頼します。続いてカスタム エージェントを確認して利用し、agents ダッシュボードからセッションの進捗を監視して作業の方向を調整します。最後に、作成されたプルリクエスト (PR) をレビューし、結果を反復して改善します。

## 前提条件

このワークショップに参加する前に、次のものを準備してください。

- [ ] 有効な **Copilot Student、Pro、Pro+、Business、Enterprise** プランを利用できる GitHub アカウント
- [ ] アカウントまたは組織で有効になっている Copilot cloud agent

> [!TIP]
> 有料プランがありませんか。認証済みの学生は [GitHub Education][callout-student-plan-education] を通じて GitHub Copilot を無料で利用できます。**Copilot Student** プランには、このワークショップで使う agent、MCP、コードレビュー、Copilot CLI の機能が含まれているため、すべての harness を完了できます。

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Cloud agent は **Copilot Student、Pro、Pro+、Business、Enterprise** で利用できます。Copilot Free は対象外です。Copilot Business または Enterprise の場合、管理者が組織に対して有効化する必要があります。

> [!NOTE]
> この harness では Model Context Protocol (MCP) を扱いません。Copilot で MCP server を使う方法については、[CLI harness](../cli/) または [VS Code harness](../vscode/) を参照してください。
