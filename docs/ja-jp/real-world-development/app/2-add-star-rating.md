前のレッスンでは、workspace を確認し、クイックチャットを試しました。次は**エージェント セッション**を開始し、プロジェクトに最初の変更を加えます。ゲームのデータには星評価がすでにありますが、ホーム ページのゲーム カードには表示されていません。エージェントに表示を依頼し、変更をレビューして、最初のプルリクエストとしてマージします。

このレッスンでは、次のことを行います。

- エージェント セッションを開始し、セッションの構成を確認します。
- エージェントにプロジェクトの小さく対象を絞った変更を依頼します。
- workspace の差分ビューで変更をレビューします。
- アプリをローカルで実行し、ブラウザーで変更を確認します。
- 最初のプルリクエストを作成してマージします。

## シナリオ

Tailspin Toys の各ゲームには星評価があり、ゲーム詳細ページにはすでに表示されています。しかし、ホーム ページのゲーム カードに表示されるのは、タイトル、カテゴリ、パブリッシャー、説明だけです。最初の練習として、各カードに既存の評価を表示するようエージェントに依頼します。小さく独立した変更なので、最初のセッションに適しています。

## セッションの構成

**セッション**は、独立した workspace でエージェントと作業する会話です。各セッションには専用の git worktree とブランチがあるため、機能追加とバグ修正など複数の作業を同時に進めても変更が競合しません。サイドバーではセッションがリポジトリごとにまとめられています。セッションを選択すると切り替えられます。

セッションには、エージェントとの**会話**、ファイルを調べて編集する際の**ツール操作**、差分付きの**変更ファイル一覧**が表示されます。

## セッションを開始して変更を依頼する

新しいセッションを開始し、プロジェクトを調べて機能を実装します。[アプリの設定][prior-lesson]では GitHub リポジトリからプロジェクトを追加しました。そのリポジトリの新しいセッションを作成し、変更を依頼します。

1. GitHub Copilot app に戻るか、アプリを開きます。
2. サイドバーの上部にある **+** を選択してセッションを開始します。
3. リポジトリに `tailspin-toys` を選択します。
4. プロンプト ボックスの下で **new working tree** と **Interactive** モードを選択し、次のプロンプトを入力します。

   ```plaintext
   ゲーム一覧ページのゲームカードに、各ゲームの starRating を 5 点満点で表示してください。評価が null の場合は "No rating yet" と表示します。カードのレイアウトはそのままにし、テストを追加して、関連するチェックを実行してください。
   ```

5. <kbd>Enter</kbd> を押して、Copilot にプロンプトを送信します。

Copilot app は、最初にプロジェクトを分離してコピーする新しい worktree を作成します。続いてプロジェクトを調べ、新機能に必要な更新対象のファイルを見つけ、コードを作成します。Copilot app で新機能を追加できました。

## 差分をレビューする

AI が生成した変更は、小さなものでもマージ前にレビューします。Copilot app 内で変更を確認します。

1. アプリ右上の **Toggle review panel** を選択します。開いたパネルで **Changes** を選択し、変更されたファイルと差分を確認します。

   ![Create PR ボタンの右側に Toggle review panel ボタンがある GitHub Copilot app の上部ツールバー](../../../_images/app-2-review-panel.png)

2. ゲーム カードの表示に使われる中心的なファイル `GameCard.astro` にコードが追加されたことを確認します。評価がある場合は表示し、`starRating` が `null` の場合は `No rating yet` を表示する、次のような小さなブロックです。

   ```astro
   {game.starRating !== null ? (
       <span class="text-xs font-medium px-2.5 py-0.5 rounded bg-amber-900/60 text-amber-300" data-testid="game-rating">
           ★ {game.starRating} / 5
       </span>
   ) : (
       <span class="text-xs font-medium text-slate-500" data-testid="game-rating-empty">
           No rating yet
       </span>
   )}
   ```

> [!NOTE]
> Copilot を含む生成 AI ツールは確率的に動作するため、生成コードは上の例と異なる場合があります。動作は比較的似たものになるはずです。

## 変更を確認する

ブラウザーを開く前に、エージェントが実行した自動チェックの結果を確認します。数値の `starRating` と、`null` の場合の代替表示の両方をテストしていることを確認してください。前提条件が不足していたり、チェックがスキップされていたりする場合は成功ではありません。インストールの要求は内容を確認してから承認します。

コードを読むだけで動作すると判断せず、Copilot に Web サイトを起動させ、更新された UI をブラウザー キャンバスで確認します。

> [!TIP]
> キャンバスは、Copilot app 内で利用できるインタラクティブなウィジェットです。後のレッスンではカスタム キャンバスを調べ、自分でも作成します。ここでは組み込みのブラウザー キャンバスを使います。

1. 次のプロンプトを送り、アプリを起動してブラウザー キャンバスで開くよう依頼します。

   ```plaintext
   アプリを起動し、ブラウザー キャンバスで開いてください。
   ```

2. しばらくするとアプリが起動し、Copilot app 内にブラウザー ウィンドウが開きます。
3. 評価があるゲーム カードに、5 点満点の評価が表示されることを確認します。
4. 確認が終わったら、次のプロンプトを送り、このセッションで起動した開発サーバーを停止するよう依頼します。

   ```plaintext
   開発サーバーを停止し、ブラウザー キャンバスを閉じてください。
   ```

## 最初のプルリクエストを作成してマージする

機能を作成できたので、新しいコードを既存のコードベースにマージするため、プルリクエスト (PR) を作成します。

1. 右上隅の **Create PR** を選択します。
2. 認証を求められた場合は **Sign in with your browser** を選択し、画面の指示に従います。
3. リポジトリのポリシーにより PR の作成前に関連 issue が必要だと Copilot が説明した場合は、その手順に従うよう確認します。
4. Copilot が PR を作成するまで待ちます。
5. チャットのすぐ上にある **PR** バブルを選択してレビュー ペインで PR を開き、内容を確認します。
6. 問題がなければ **Ready to merge** を選択します。
7. 表示されたダイアログで **Merge pull request** を選択し、PR をマージします。

## まとめと次のステップ

GitHub Copilot app を使い、最初の変更をリリースしました。このレッスンでは、次のことを行いました。

- エージェント セッションを開始し、セッションの構成を確認しました。
- エージェントにゲーム カードの小さく対象を絞った変更を依頼しました。
- workspace の差分ビューで変更をレビューしました。
- アプリをローカルで実行し、ブラウザーで星評価を確認しました。
- PR 1 を作成してチェックをレビューし、明示的にマージしました。

次は、[フィルタリング issue を起点に Plan と Autopilot モードを使って][next-lesson]、より大きな機能を実装します。
